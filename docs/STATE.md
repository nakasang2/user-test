## 既知の制約（対応済みだが把握しておくこと）
- **削除済みタスク・質問の扱い**は excludedAt（集計対象外の印）方式で恒久対応済み。削除する「前」に印を付けるので、後から推測しない。手動での除外／復帰もできる
- **感情検出のモデル読み込みに失敗しても、誰も気づけない**。参加者向けの「検出エラー」表示は撤去した（参加者には対処できず、進行も止まらないため）。調査者向けの通知は元々無い。実際の症状は「そのセッションだけ感情のグラフが出ない」。`track()` の送信先が未選定（本番では no-op）なので、計測を足すならプロバイダ選定とセットで
- 集計対象外（excludedAt）の残る制約: 自由回答（open）は「集計から外した項目」パネルに列挙されない（`aggregateScores` がスコア型しか扱わないため）。生きた自由回答に印が残る経路は塞いだので実害は無いが、削除した自由回答質問を画面から復帰させる導線は無い（CSV には残る）
